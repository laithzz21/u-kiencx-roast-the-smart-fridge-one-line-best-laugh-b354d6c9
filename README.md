## The entry

> My smart fridge judges my 2 a.m. snacks out loud, then texts my scale — even my leftovers have a group chat now.

112 characters, one line — inside the 160-character limit.

## Run

```sh
python3 main.py
```

The program validates the entry (at most 160 characters, exactly one line),
prints it to stdout, and writes it to `entry.txt` under
`$MAKEFUN_OUTPUT_DIR`, `$MAKEFUN_OUTPUT`, or a per-entry `/tmp` path.
